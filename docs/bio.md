# 袁淑芳

姓名是「袁淑芳」：淑（三点水），不是舒；芳（草字头），不是方。不写成袁舒方，也不写成袁舒芳。

河南西平芦庙乡盘龙桥的乡村中医。本页只写公开报道和家属访谈里对得上的事。对不上的，单独标在最后，不写成她的生平。

同页：[生平网页](bio.html)

## 人

袁淑芳，西平县芦庙乡盘龙桥村人。2006年去世，享年九十七岁，行医约八十年。生年多按享年倒推，本站不把某月某日写成确凿生日。

十六岁开始学医、行医。学医从哪一支起，报道不一致，并列在这里：

- 驻马店当地报道写她出身书香门第，幼承家技，是娘家世代中医这一支的继承人。
- 大河报采访写，她学医离不开丈夫王鸣周一家。王鸣周在西平、舞阳、遂平一带被称作三县名医。
- 2026年11月中新社引孙子王克中的话，说她最初跟随世代从医的爷爷学。同一篇里也写她白天种地，夜里靠煤油灯或月光认字、背方。

网上另有「十六岁嫁过去才从不识字学起」的说法，已有文章指出这和家属说法不一致。本站不把「不识字」写成她的生平。

## 坐诊

她长期在村里坐诊。诊室在不同报道里叫袁氏中医，也叫袁氏妇科。当地尤其记得她看月经、不孕，以及小孩的发热、咳嗽、腹泻，口头上叫她送子观音。

家属说她白天还下地，晚上借月光或煤油灯背书、抄方。她常说的意思是：学医先修德，心里没有病人，方子再好也没用。八九十岁仍有人找她看病。枕边还放着医书。听说老病号远道而来，躺着也要问清楚。

## 著述和奖

公开报道还提到她写过《骨髓炎治验》《大面积烧伤的中药疗法》《顽固性癫痫治验》《男女不孕病治验》，并写到河南省、驻马店市科技进步二等奖各一项。奖状和书稿不在这座网站上，这里只记报道里的话。

## 墓碑

她有一个红本子。晚年从里面挑出常用验方，交给二儿子王泰升，要刻在自己的墓碑上。她的话大意是：祖国的医学不是我一个人的，不能带进土里，让后人不花钱或少花钱就能看好病。

碑立在盘龙桥的庄稼地边，花岗岩。正面是「慈母袁淑芳之墓」。两旁对联是：上善若水，医者佛心，年近百岁却无私；孔德之容，唯道是从，方碑明示福后人。对联下面才是药名和剂量。大河报回访写过，碑上药名之间没有标点。

立碑年份有两种写法。驻马店当地一篇写：2006年夏天她把方子交给王泰升；2008年清明，王泰升从北京赶回，碑在山东刻了一个多月，清明前立上。另有报道写成 2007 年清明。本站两说并列，不改成一个日子。

碑立起来之后，各地有中医和学子来抄、来拍。许昌、漯河一带行医的段红霞反复出现在采访里。她说 2019 年第一次来，在碑前抄了一整天；后来又来核对、拍照，整理成电子稿。她特别提到治疗痛经的方子自己用过。这些是别人的记述，不是碑上的药。

2026年11月3日大河报再次报道之后，王克中说碑前每天有很多人来，地上被踩出一条路，碑前摆了花和水果。

## 方子有多少

这一条报道彼此打架，本站不抹平：

- 多数报道，包括碑面传抄，写的是一百个验方，药名和剂量都刻上。
- 2026年11月5日中新社引王克中：碑体放不下，只刻了五十多个基础方；她离世前一年整理过二百多个。
- 2026年11月6日大河报再引王克中：碑上只是一部分；手写原稿初步估计有二百多个，找到后会公布。

本站验方库只对照已经抄下的墓碑，不把「还没找到的原稿」算进库里，也不因某篇报道改碑上的条数。

## 后人

家里后来仍有人行医。报道里出现过孙子王克中、侄子王泰希。王泰希回忆过：点灯的油也不够，夜里借月光读书；她开的药，自己吃过，有效。

王泰升本人后来的行医和化学药方，不是这块碑上的方。本站验方只对照墓碑，不把儿子的方子混进来。

## 这篇不采用

2025年4月一篇百家说史，以及同类转载，把几件对不上的事写成了她的生平。本站不收：

- 出生地写成西平县吕店乡袁庄。家谱网站 2014 年摘录里有「1919年生、吕店乡袁庄」。这和盘龙桥、2006年九十七岁对不上。
- 家传秘方《九色灵药》、诊所名《阿基听》。后一个名字在转载里已经不成词。
- 在兴义结识王鸣周、养育七个子女、1960年代王鸣周入狱、1979年平反。家属访谈和驻马店报道没有这些情节。
- 祖父天天带她上山采药、每晚背《药典》。中新社只记到「跟随爷爷学」，没有这些细节。

网上还流传一张白发老人的照片，说是袁淑芳。2026年11月6日王克中对大河报说，那张不是他奶奶。家里能找到的彩色照片只有一张。本站不用那张网图。
